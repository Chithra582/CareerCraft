# Career Readiness Advisor Skill

## Overview
The `career-readiness-advisor` skill provides strategic career coaching feedback, replaces generic buzzwords with measurable outcomes using the Google XYZ formula, and outlines targeted upskilling roadmaps.

## Core Capabilities
- **Bullet Point Rewriting**: Re-engineers passive or vague resume bullets into accomplishment statements using the Google XYZ framework ("Accomplished [X] as measured by [Y] by doing [Z]").
- **Buzzword Decontamination**: Flags overused clichés (e.g., "results-driven", "synergy", "hard worker") and replaces them with demonstrable technical competencies.
- **Skill Pathway Mapping**: Directs candidates toward open-source contributions, high-value certifications, and portfolio project ideas tailored to their target industry.
- **Interview Talking Points**: Distills key resume highlights into conversational talking points for behavioral and technical interviews.

## Inputs
- `bullet_points`: List of existing candidate resume bullet points.
- `target_role`: Target job category (e.g., Full Stack Engineer, Cloud Architect).

## Outputs
- `revised_bullets`: Re-engineered bullet alternatives with quantified metrics.
- `flagged_cliches`: List of identified buzzwords and recommended replacements.
- `portfolio_project_ideas`: Suggested practical projects to demonstrate missing proficiencies.
